# novel-comic-agent

把一段想法或一整部小说，变成可以逐页翻看的长篇条漫。文本模型负责规划与分镜，
图片模型负责逐格作画，台词和拼版由代码渲染——每一格干净、可读、风格统一。

**生成前先看到价格**：输入文字 → 规划器给出页数、角色表、每页拍点和预估花费 →
你确认 → 逐页生成，实时看到每一格和成品页。不满意随时取消，一分钱不花。

## 它能做什么

- **先规划，再花钱**：确认卡上写清楚几页、哪些角色、选哪位画师、预计花费（生图 +
  文本 token 分项列出）、每页拍点。取消不产生任何费用。
- **一句话到整本小说都收**：一句想法出一页；成段文字自动分页改编——规划器给出
  全部拍点，逐页生成；单批最多 20 页，继续投喂原文就能追加页面。
- **同一会话续写**：在会话视图里再发一段文字，规划器自动判断是"接续本作品"
  （页码接着排、沿用角色与画风）还是"另起新作"。
- **参考图换角色**：上传角色参考图，规划器建立"原文角色 → 参考图角色"的映射
  （比如把斗破苍穹的主角换成熊二），编剧按映射改写台词与画面，画格自动垫图
  保持长相一致——剧情大致不变。
- **跨页一致性**：全部页共用一份剧本（全局风格卡 + 角色外貌卡），生图时自动拼进
  每格提示词；整本小说也不会画着画着换脸换画风。
- **断点可续**：每页每格独立落盘，中断后点「恢复」，已完成的自动跳过。
- **画师风格卡**：`skills/*.md` 一个文件一位"画师"（吉卜力、伊藤润二、小畑健……），
  规划器按剧情气质自动选，也可以指定；上传自己的 .md 即时生效。

## 快速开始

```bash
git clone https://github.com/Fenglin6666/novel-comic-agent.git
cd novel-comic-agent

python -m venv .venv
.venv\Scripts\pip install -e .            # Windows；Linux/macOS 用 .venv/bin/pip
.venv\Scripts\python -m uvicorn web:app --host 127.0.0.1 --port 8765
```

打开 <http://127.0.0.1:8765>，点侧栏右上角 **⚙️ 模型配置**：

- **文本模型**：DeepSeek 或 智谱 GLM（选厂商自动填端点与模型名），粘贴 API Key
- **生图模型**：字节火山方舟 Seedream flash（¥0.12/张），或任何 OpenAI 兼容的生图端点

配置保存在本机 `comic_out/web_config.json`（已在 .gitignore，不会进 git），
保存即生效、重启后仍生效。

## 怎么用

1. 输入一句话、几段文字或一整章小说 → 点「生成」
2. 看确认卡：页数 / 角色 / 画师 / **预估花费** / 分页拍点 → 确认或取消
3. 逐页生成实时可见：每一格 → 成品页；侧栏与标题显示进度，随时可以停止
4. 停在会话视图里继续输入 = **续写**；点「＋参考图」上传形象 = **换角色**
5. 侧栏「作品」是全部成品，点击看大图；会话可以重命名

生成中切到别的会话/作品页不会中断任务，顶部横幅点一下就能回到生成现场。

## 一次生成的花费

| 项目 | 单价 | 估算方式 |
|---|---|---|
| 生图 | Seedream flash ¥0.12/张 | 页数 × 版式格数（每页 1-8 格，按约 4 格估） |
| 文本 token | 按所配模型计费 | 规划一次 + 每页一次分镜写作（含纠错余量） |

一页 4 格的短篇大约 **¥0.5**（生图 ¥0.48 + 文本几分钱）；确认卡上会按你配置的
模型给出精确的分项估算。实际以 API 账单为准。

## 项目结构

| 位置 | 职责 |
|---|---|
| novel_comic_agent/plan.py | 规划器：输入分析、页数、角色表、拍点、画师选择、成本估算 |
| novel_comic_agent/adapt.py | 长文本逐页流水线：写分镜 → 版式 → 补缺格 → 合成（页幂等） |
| novel_comic_agent/comic_tools.py | 漫画工具链：剧本 / 分镜 / 版式 / 生图 / 合成 |
| novel_comic_agent/session.py | 会话状态机 + 事件流 + 断点恢复 |
| novel_comic_agent/webconfig.py | 前端模型配置（密钥只落本机文件） |
| web.py + web/ | FastAPI 服务（SSE 流式）+ Vue 3 单页界面（本地 vendor，零构建） |
| tests/ | 45 个离线测试（模型替身只存在于测试文件内） |

```bash
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\ruff check novel_comic_agent tests web.py comic.py
```
